統計口徑：最新流通餘額取官方 OutstandingAmount；年度發行量按 IssueDate 與 IssueAmount 統計。部分普通公司債無 BondCode，仍保留有效紀錄，僅排除內容相同的重複資料；發行日晚於資料基準日的紀錄不列入當期統計。不同幣別不混加；可按官方掛牌狀態代碼篩選，代碼 2、3、5 暫以原始代碼顯示，尚不自行定義法律或交易意義。ISSBD10 國際債券（含短天期 ELN）獨立呈現；其 IssueAmount 為 0 的紀錄不推算發行量。資料由 GitHub Actions 每日擷取 TPEx 官方 API 後存入本站；未成功取得資料時會明確顯示錯誤，不會顯示假資料。
